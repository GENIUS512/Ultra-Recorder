✨ Возможности
🎥 Запись
Три источника: весь экран, отдельное окно, произвольная область

Аппаратные кодеки: NVENC (NVIDIA), AMF (AMD), QuickSync (Intel), Media Foundation

Умный выбор: приложение само проверяет, какие кодеки реально работают на вашем ПК

DXGI Desktop Duplication через ddagrab — минимальная нагрузка на CPU

Прямой GPU-путь: кадр идёт с экрана прямо в энкодер без копирования в RAM

Гибкая настройка: FPS, разрешение, CRF/CBR/VBR, пресеты скорости

🔊 Звук
Системный звук через WASAPI loopback — без «Stereo Mix»

Микрофон — отдельная дорожка с регулятором громкости

Автосинхронизация: звук подгоняется под видео через atempo, без рассинхрона на длинных записях

До 320 kbps AAC на выходе

📡 Стриминг
Twitch и YouTube Live из коробки

Свой RTMP сервер

Тест соединения перед эфиром

Стрим и запись одновременно — нет (по требованию платформ)

📷 Веб-камера
Живой превью в приложении

Наложение поверх записи: положение, размер, форма, прозрачность, рамка

Зеркало, поворот, яркость, контраст, насыщенность

⌨️ Глобальные хоткеи
Старт/стоп записи (F9)

Стрим (F8)

Скриншот (F10)

Показать/скрыть окно (F11)

Работают внутри игры

📸 Редактор скриншотов
Карандаш, линия, прямоугольник, эллипс, стрелка, текст

Блюр и пикселизация конфиденциальных данных

Обрезка (crop), отмена/повтор (Ctrl+Z / Ctrl+Y)

Копирование в буфер (Ctrl+C)

⚡ Производительность
Игровой режим: минимальное вмешательство в игру

Оверлей REC поверх игры, не попадает в запись

Исключение из power throttling Windows

High-performance power plan на время записи (с восстановлением)

Низкоприоритетные потоки FFmpeg — игра не тормозит

Тонкая настройка QSV VDEnc для слабых Intel iGPU
