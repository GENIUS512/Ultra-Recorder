❓ ЧАСТЫЕ ВОПРОСЫ
</div><details> <summary><h3>🎬 <b>Запись ускоренная или замедленная</b></h3></summary>
Включи Force constant frame rate в Settings. Эта опция пересчитывает PTS по wall-clock времени и убирает рассинхрон.

</details><details> <summary><h3>🔇 <b>Нет звука в записи</b></h3></summary>
Установи PyAudioWPatch: pip install PyAudioWPatch

Проверь, что выбран тот же output device, на который ты слушаешь

Перезапусти приложение

</details><details> <summary><h3>🐌 <b>Игра лагает во время записи</b></h3></summary>
Включи Game mode

Понизь FPS до 30 и разрешение до 720p

Включи Low-power hardware encoder (QSV) для Intel

Отключи Direct GPU path (иногда драйвер его не тянет)

</details><details> <summary><h3>📦 <b>FFmpeg не найден</b></h3></summary>
Установи через winget install Gyan.FFmpeg и перезапусти приложение. Приложение читает свежий PATH из реестра — ждать перезагрузки Windows не нужно.

</details><details> <summary><h3>📡 <b>Стрим не запускается</b></h3></summary>
Нажми Test connection на вкладке Stream. Если ошибка — проверь:

Ключ стрима скопирован полностью

Битрейт не превышает лимиты платформы (Twitch: 6000 kbps для непартнёров)

Антивирус не блокирует исходящие RTMP

</details><details> <summary><h3>🎞 <b>Видео в MKV — как открыть в редакторе?</b></h3></summary>
Перемуксируй в MP4 без перекодирования:

bash
ffmpeg -i rec.mkv -c copy rec.mp4
</details>
